# ADR-0002: Fairness definition
Status: Accepted | Date: 2026-10-21

## Context
Open decision from the baseline document (D2); resolved in HLD section 3.

## Decision
Equal allocation counts per user within a rolling 14-day window, among eligible users; Jain's index as the metric.

## Consequences
Rationale: Simple, explainable, measurable.
Cost accepted: Ignores differing user needs.
